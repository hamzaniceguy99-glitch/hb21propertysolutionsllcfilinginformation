Program 02 · The letter in the drawer

Code violations & open permits

Open permits from work done decades ago and code enforcement letters are the two things that quietly stop a sale. We find out what is actually outstanding, get licensed contractors to do the work and schedule the inspections, so the file can be closed rather than inherited by a buyer.
